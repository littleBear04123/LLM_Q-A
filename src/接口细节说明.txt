
4.4.1 用户管理模块接口

4.4.1.1 POST /api/users/init - 用户初始化/登录接口
（1）功能：用于用户登录或初始化，如果用户不存在则创建新用户
（2）模块归属：用户管理模块
（3）参数要求：
请求方式：POST
请求头：Content-Type: application/json
请求体：{ "username": string }
返回值：{ "success": boolean, "user": { "id": number, "username": string }, "session": { "token": string, "id": number }, "hasUnfinishedScenario": boolean, "unfinishedScenario": object }
（4）用途：用户登录认证，建立会话
（5）说明：POST /api/users/init 是一个用户初始化/登录接口，它属于用户模块。该接口的主要功能是接收前端传递的用户名，然后在数据库中查找或创建用户，并生成一个新的会话令牌返回给前端。这个接口与前端的LoginView.vue组件和userStore.js中的login方法相匹配。接口要求参数为JSON格式的请求体，其中必须包含非空的username字段。接口返回包括用户信息(id和username)、会话令牌(sessionToken和sessionId)以及其他相关信息。
该接口的实现逻辑是：首先验证请求体中的用户名参数，如果用户名为空则返回错误；然后调用UserModel的findOrCreate方法查找或创建用户；接着调用createSession方法为用户创建新的会话；最后返回用户信息和会话数据。接口采用POST请求方式，符合RESTful API的设计规范，专门用于用户初始化和登录场景。

4.4.8 数据库模块接口（后端内部使用）

4.4.8.1 用户相关数据库接口
（1）findOrCreate(username): 查找或创建用户
（2）createSession(userId): 创建用户会话
（3）getSessionByToken(token): 根据令牌获取会话
（4）deleteUserAccount(userId): 删除用户及其所有相关数据

4.4.8.2 项目相关数据库接口
（1）createProject(userId, projectName, description, requirementText): 创建项目
（2）getProjectsByUser(userId): 获取用户的所有项目
（3）updateProjectUML(projectId, plantUmlCode): 更新项目的UML代码
（4）deleteProject(projectId, userId): 删除项目及其所有相关数据

4.4.8.3 用例相关数据库接口
（1）createUseCase(projectId, useCaseName, actor, description): 创建用例
（2）getUseCasesByProject(projectId): 获取项目的用例列表
（3）updateUseCaseStatus(useCaseId, status): 更新用例状态
（4）clearUseCasesByProject(projectId): 清理项目的全部用例

4.4.8.4 场景相关数据库接口
（1）createScenario(useCaseId, title, initialInput): 创建场景
（2）getScenariosByUseCase(useCaseId): 获取用例的场景列表
（3）updateScenarioContent(scenarioId, generatedScenario, statusTable, scenarioPlantUmlCode): 更新场景内容
（4）getScenarioByUseCase(useCaseId): 根据用例获取场景
（5）updateScenarioStatusTable(scenarioId, statusTable): 更新场景状态表
（6）getScenarioStatusTable(scenarioId): 获取场景状态表

4.4.8.5 消息相关数据库接口
（1）saveMessage(scenarioId, role, content): 保存消息
（2）getMessageHistory(scenarioId, limit): 获取消息历史

4.4.9 认证机制说明
（1）所有需要认证的接口都使用validateSession中间件进行会话验证
（2）通过X-Session-Token请求头传递会话令牌进行身份验证
（3）会话信息存储在req.session对象中，包含user_id等用户标识信息
